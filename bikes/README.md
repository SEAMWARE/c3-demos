# Boston bikes

`launch.sh` - a coraine in RAM on port 1092 (`PORT`), Boston's bike-share stations and districts read
from data.boston.gov (`c3/examples/ckan-bikes.sh`; needs the network). In c³, Explore: connect to
`http://localhost:1092`. Ctrl-C stops it. See the [demos](../README.md#running-a-demo).
